# Delivery Exception Copilot

**Zion Delivery Exception Copilot** — detects delivery delays early and auto-drafts customer communications and recovery actions.

> Part of the **Zion AI App Network** — see [ZION_APP_NETWORK.md](./ZION_APP_NETWORK.md) for the full mesh of interlinked apps.

Live app: https://ziontechgroup.com/delivery-exception-copilot/

## ✨ Features
- **Early delay detection** — predicts at-risk shipments from carrier scans, weather and traffic.
- **Auto-drafted comms** — proactive, on-brand customer messages with new ETAs.
- **Recovery playbooks** — suggests reship, upgrade or refund actions by order value.
- **Carrier scorecards** — exception rates by carrier, lane and service level.
- **WISMO deflection** — cuts “where is my order” tickets with proactive updates.
